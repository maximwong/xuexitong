基于java面向网页版学习通开发的刷课脚本，有自动连播视频和使用穷举法回答视频内知识点问答的能力，但不能自动完成各种线上测试，完全无广无付费
使用说明
学习通视频连播助手 1.1.0
安装文件：同目录下的 chaoxing-study.user.js。
从 1.0.0 升级：在 Tampermonkey 中打开旧脚本，用新版文件全部内容替换并保存，再刷新课程页面。脚本名称和命名空间保持一致，无需同时安装两个版本。
安装与开始
在 Edge 或 Chrome 中，从 Tampermonkey 官网安装扩展。
点击扩展图标 →「添加新脚本」，删除默认内容，复制 chaoxing-study.user.js 全部代码进去，按 Ctrl+S 保存。也可以在 Tampermonkey 管理面板的「实用工具」中从文件导入。
如果扩展提示脚本运行权限不足，按提示在扩展详情中打开「允许用户脚本」。具体选项随浏览器版本变化，参见 Tampermonkey 官方说明。
登录学习通，打开具体课程的视频播放页，刷新一次。
点击右下角面板的「开始连播」。首次播放若被浏览器阻止，先手动点击视频播放按钮，再点击「开始连播」。
已实现功能
识别当前页及同源多层 iframe 中可见的 HTML5 视频。
同页多段视频按页面顺序播放；收到真实播放结束事件后，再处理后续视频。
提供 1 / 1.25 / 1.5 / 1.75 / 2 倍速和静音选项，设置保存在当前站点浏览器存储中。默认 1 倍、有声音。
播完本页视频后等待 5 秒，再点击页面已有的下一节入口；倒计时期间可以暂停取消。
优先从新旧章节目录定位下一节，支持跨章进入折叠目录中的下一小节；找不到目录时，再使用页面的下一节按钮。进入学习步骤页后，可自动点击“视频”页签。
同时监听视频结束事件和播放器原生结束状态，处理结束事件遗漏及开始时视频已结束的情况。
在同一标签页、同一课程的正常页面跳转中保留启动状态，最长 4 小时。跨站点域名跳转可能需要重新点击开始。
手动暂停或一般页面暂停后停止连播；已识别的视频弹题暂停会进入弹题处理流程。播放拒绝、验证弹窗、加载超时、长时间不推进时给出提示。
单次点击下一节后检查是否出现新视频；20 秒未识别到新视频就停止，避免重复点击。
「查看诊断信息」显示页面路径、视频数量、播放器状态；不包含网址查询参数、媒体地址、Cookie 或账号内容。
视频弹题逐项尝试
面板新增“视频弹题逐项尝试”开关，默认开启；只在点击“开始连播”后运行。
识别同源播放器内的学习通视频弹题，读取可点击的单选或多选选项。
单选题按页面顺序 A、B、C……逐项选择并提交，最多支持 8 项。
多选题先尝试单项，再按组合项数增加尝试组合。最多支持 5 个选项、31 种非空组合；每次切换组合时清除前一次选择。
每次提交后等待新反馈。明确答错才尝试下一项；结果未更新时不会沿用上一次的错误提示继续提交。
弹窗关闭后恢复视频；如果页面提示回答正确并出现“继续播放”等按钮，点击一次继续。
这是逐项试选，不是题库解题，也不保证答对。网站可能记录尝试次数。没有识别到反馈、候选项已用完、页面限制重试或处理超过 3 分钟时，脚本会暂停提示；15 秒未收到结果时不会自动重发。
点击“暂停连播”或关闭弹题开关可取消尚未提交的操作。功能限定在 .ans-videoquiz 等视频弹题容器，不处理普通章节测验、作业和考试页面。暂不支持无原生单选/复选控件的自定义选项、填空题、多个题组以及跨域弹窗；遇到这些情况需手动处理。
兼容范围与限制
目前按 *.chaoxing.com 下 /mycourse/、/mooc-ans/ 页面适配。面板只在顶层页面出现。章节跳转支持新版 #coursetree / .posCatalog_select 目录、旧版 .ncells / h4.currents 目录，以及 #prevNextFocusNext、#right1、.nextChapter 控件。
本版已修复已识别的导航缺口并完成回归测试，尚未使用你的真实课程账号联调。 不同学校、课程版本、内嵌域名可能需要进一步适配。
跨域 iframe 受浏览器同源策略限制，当前版本仍无法控制其中的播放器和弹题；其他跨域挂件不会阻止已识别视频播完后的跳转。
无视频且没有可识别视频页签的页面、章节测验、文档和作业需要手动处理。
播放器原生状态显示已结束时，连播可继续导航，但不会将其写入平台为“任务已完成”。
播放器把倍速重置后，脚本保留播放器的实际速度。平台切换标签页时暂停视频，也会停止连播。
自动播放仍受浏览器限制。MDN 对 play() 的说明解释了这种情况。
本脚本只控制页面播放与导航，不向进度接口发送请求，不修改任务完成状态。视频播完不等于平台已确认任务点完成，请以课程页面显示为准。
脚本没有第三方依赖、题库或账号上传，也不直接调用进度或答题接口。网站播放器本身仍会按平台逻辑加载视频、记录学习进度；点击弹题提交按钮会触发网站自身的答题请求。
遇到问题
没有面板：确认脚本启用且扩展允许运行用户脚本，并进入具体课程播放页，而不是课程列表。
识别不到视频：先手动进入「视频」标签并等待加载，再点击「重新识别」。如果提示跨域或仍识别失败，可提供删除问号后参数的页面网址及面板诊断信息，以便继续适配。
下一节停住：可能进入了测验/课件、平台提示任务未完成、视频跨域，或目录结构不同。按页面提示处理后手动进入下一段视频，再开始连播。
停用：点击「暂停连播」；要彻底停用，在 Tampermonkey 面板关闭该脚本并刷新页面。
